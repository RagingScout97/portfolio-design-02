# Portfolio OS — RagingScout97

Interactive game-menu portfolio for **Prakhar Singh Rajput** (`RagingScout97`).

## Stack

- Next.js (App Router) + TypeScript + Tailwind CSS v4
- Framer Motion + canvas arcade mini-game
- Static content in `src/data/portfolio.ts` (no backend)

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Content

Edit identity, skills, experience, and projects in [`src/data/portfolio.ts`](src/data/portfolio.ts).

## Deploy

Push to `main` → Vercel auto-deploys project **portfolio-design-02**.

- Live preview: https://portfolio-design-02.vercel.app
- Custom domain cutover: see [DOMAIN-CUTOVER.md](DOMAIN-CUTOVER.md)
